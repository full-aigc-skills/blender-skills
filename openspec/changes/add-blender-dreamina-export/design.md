## Design

Keep installation and both export modes in one independently installable skill because the official Blender uploader owns all three actions. Use the user-supplied official manual as the interface baseline; check live labels and version before acting. The camera route validates the newly rendered video, while the local route reuses an existing video. Record link creation and web reference loading separately. Do not couple this skill to the Codex Blender Connector or to unshipped vendor internals.
