# Reference recreation acceptance checklist

- [ ] Source hash, technical properties, and target segment are recorded.
- [ ] Shot/action table separates observations from inferred or occluded content.
- [ ] Editable scene, active camera, frame range, scale, and persistent prop identities are explicit.
- [ ] Full preview playback and representative source/reconstruction frame pairs were inspected.
- [ ] Timing, screen position, scale, contact order, gait, floor penetration, prop continuity, and camera visibility have statuses.
- [ ] Encoded preview properties and artifact hashes were verified.
- [ ] Optional provider upload, cost, task id, download, and result quality have separate evidence.
- [ ] Unsupported platforms/providers remain `UNVERIFIED` rather than being inferred from portability.
