# Blender → 即梦参考视频

本技能覆盖官方 Blender 上传器的安装和导出交接。用户提供的官方手册将上传器称为“即梦 Seedance 2.5 白模渲染上传器”；下载入口为 <https://jimeng.jianying.com/ai-tool/home>。安装包和界面可能随版本变化，操作前以实际官网包和 Blender 界面核对。它与 `blender-mcp-setup` 所用的 **Blender Connector / Codex N 面板**是两个插件。

## 什么时候使用（When to Use）

- 场景和相机已准备好，需在 Blender 中生成白模视频：选择**相机渲染**。
- 已有渲染好的白模视频：选择**本地上传**，不要重复渲染。
- 还没有可用场景或视频：先完成白模制作。可按技能名使用 `blender-video-original` 或 `blender-video-recreate`；单独安装时使用 `npx skills add full-aigc-skills/blender-skills --skill <skill-name>`。本技能不依赖它们的文件。

## 输入与前置条件（Prerequisites）

需要当前 Blender 场景或已有本地白模视频、实际官网下载的插件包（如需安装）、可访问的即梦网页，以及本次安装／上传操作的授权。仅索取完成当前路径所需的信息。

## 执行流程（Workflow）

### 安装和就绪检查

Step 1. 先检查 Blender 内是否已有官方上传器，并记录 Blender 版本、插件显示名称、是否启用。已就绪则跳过安装。

Step 2. 需要安装时，从上述即梦官网获取适用于当前 Blender 的插件 ZIP；确认来源和版本。安装或启用属于环境变更，执行前取得本次操作授权。不要用第三方镜像、猜测 ZIP 文件名或自行解压重组。

Step 3. Blender 中打开 **Edit → Preferences → Add-ons → 右上角菜单 → Install from Disk**，选择下载的 ZIP，执行安装，保持“即梦 Seedance 2.5 白模渲染上传器”启用。

Step 4. 返回 3D View，按 **N** 或点击右侧箭头展开 Sidebar，进入 **Jimeng** 面板。看不到面板时先查安装、启用状态和实际兼容版本，不把 Codex 面板视为成功。

### 导出并交接

Step 1. 确认要交接的场景或本地视频、输出目录和覆盖范围；执行任何实际上传前确认本次用户授权。网页登录、付费生成和发布按用户当次要求另行处理。

Step 2. **相机渲染**：在 Jimeng 面板的“视频上传方式”选“相机渲染”，核对相机、分辨率、保存位置及实际界面提供的设置，点击“渲染”。等待本地视频完成，检查文件存在、非空且可播放；不要把渲染启动当作完成。

Step 3. **本地上传**：选“本地上传”，指定已有白模视频文件；检查文件存在、非空且可播放。界面若有额外准备按钮，按实际标签操作，不把本地视频模式误写成必须再渲染场景。

Step 4. 点击 **“上传至即梦生成”**。记录插件返回的链接及页面状态；在即梦 Web 页面确认所选白模视频已作为**参考视频输入**。若页面要求登录或视频尚未载入，报告当前状态并继续按实际页面排查。

## 验证与交付证据（Validation）

分别报告：插件可用、本地视频验证、链接产生、网页打开、参考视频载入，各项用 `PASS` / `FAIL` / `UNVERIFIED`。提供本地文件路径、媒体参数和检查证据；含临时 token 的链接不要写入长期回执。**链接产生不等于网页已读到视频；参考视频载入不等于 Seedance 任务已提交或生成完成。**

当只需手动操作指导时，可直接使用 [相机渲染示例](examples/camera-render.md) 或 [本地视频示例](examples/local-video.md)。没有真实插件或网页访问能力时给出步骤并标记运行结果 `UNVERIFIED`，不编造自动上传接口。

## Rules 与能力边界（不适用场景）

不把 Blender Connector 当作即梦上传器，不把本地导出、生成链接、参考视频载入或 AI 成片合并为一个成功状态；不自动登录或提交付费任务。

## Gotchas（常见问题与恢复）

面板缺失时检查插件名称、启用状态和版本；链接出现但网页无参考视频时记录网页提示与链接时效，不重复上传直到确认前一次结果；视频不可播放时先修复本地产物。
